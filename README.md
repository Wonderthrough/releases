# Wonderthrough for Mac

Downloads and automatic updates for the Wonderthrough desktop app.

**Get it at [wonderthrough.com/download](https://wonderthrough.com/download).**

Requires macOS 13 or later on Apple Silicon (M1 or later). Each release is signed by Wonderthrough, LLC and notarized by Apple.

This repository only hosts release files; Wonderthrough's source code is not public. Release notes: [wonderthrough.com/changelog](https://wonderthrough.com/changelog).

Use of Wonderthrough is subject to the [Terms of Service](https://wonderthrough.com/legal/terms).
